# Contributing

Thanks for helping improve **repo-clean**!

## Development

```bash
npm i
npm run build
node bin/repo-clean --help
```

## Releasing (maintainers)

This repo includes a GitHub Actions workflow that can create a GitHub Release when you push a tag like `v0.1.0`.
Optional: publish to npm by adding `NPM_TOKEN` in the GitHub repo secrets.

## Code style

- Keep changes small and focused.
- Prefer readable code over clever code.
- Add/adjust docs when you change behavior.
